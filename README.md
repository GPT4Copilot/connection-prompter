# Connection Prompter V1.2.2

原生 macOS 会议提词器，支持 macOS 14 及以上版本，仅支持 Apple Silicon。

## 直接使用

双击 `dist/Connection Prompter 1.2.2.app`。左侧文稿库可以新建、搜索、切换和删除稿件；右侧编辑器会自动保存当前内容。用空行分段，然后点击“进入主持”。旧版单文稿会在首次启动时自动迁移到文稿库。

主持浮窗默认位于屏幕顶部中央，可拖动和缩放。开启“鼠标穿透”后，使用 `⌥⌘X` 恢复鼠标操作。

## V1.2.2 修复与主持场景

- People View 现在会继续使用“背景透明度”设置。
- 鼠标移到主持浮窗的边缘或四角时，会显示窗口缩放光标。
- “主持时隐藏编辑页”默认开启；也可取消勾选，保持编辑窗口可见。

## V1.2.1 修复与快捷键

- 拖动主持浮窗的速度滑杆只会调整速度，不再带动整个窗口；拖动其他正文或背景空白区域仍可移动浮窗。
- 主持状态下可用 `←`、`→` 每次减慢、加快 0.1 行/秒，并继续用 `↑`、`↓` 控制上一页、下一页。

## V1.2 新功能

- 主持浮窗控制条可直接拖拽调整 0.1–3.0 行/秒的自动滚动速度，并实时显示当前值。
- `⌥⌘←` 和 `⌥⌘→` 可在任意应用或鼠标穿透状态下减慢、加快自动滚动。

## V1.1 新功能

- 背景透明度支持 0%–100%；100% 时浮窗背景完全消失，后方应用可见，主持文字仍保留高对比度阴影。
- 主持浮窗支持连续自动滚动，可在“显示设置”中选择 0.1–3.0 行/秒，并用浮窗控制栏开始、暂停或回到开头。
- 鼠标滚轮和触控板可以手动调整阅读位置；手动调整时自动滚动会暂停。
- 采用类似备忘录的多文稿列表，按今天、昨天和更早分组，并保留每份稿件的标题、正文预览和更新时间。

## 快捷键

- `↑`：上一页（应用内且未编辑文字时）
- `↓` 或 `Space`：下一页（应用内且未编辑文字时）
- `←`：减慢自动滚动 0.1 行/秒（主持状态且未编辑文字时）
- `→`：加快自动滚动 0.1 行/秒（主持状态且未编辑文字时）
- `⌥⌘↑`：全局上一页
- `⌥⌘↓`：全局下一页
- `⌥⌘←`：全局减慢自动滚动 0.1 行/秒
- `⌥⌘→`：全局加快自动滚动 0.1 行/秒
- `⌥⌘X`：全局切换鼠标穿透
- `⌥⌘P`：全局显示或隐藏主持浮窗

## 本地数据

文稿库、当前稿件、滚动位置和显示偏好会在编辑后约 350 毫秒自动保存。应用保留一份上次存档备份；主存档损坏时会自动尝试恢复备份。应用不请求网络、麦克风或摄像头权限。

## 打开工程

使用 Xcode 打开 `ConnectionPrompter.xcodeproj`，选择 `ConnectionPrompter` scheme 后运行即可。

## 真实会议验收建议

- 在普通窗口和全屏 Zoom 中确认浮窗均可见。
- 切换 Space，并在双显示器间移动浮窗；拔掉副显示器后确认浮窗回到主屏。
- 开启鼠标穿透，确认可以点击后方 Zoom；再用 `⌥⌘X` 关闭穿透。
- 检查滚轮或触控板不会因轻微滑动连续误翻页。
- 检查 0%、50% 和 100% 背景透明度，并确认 100% 时能清楚看到后方应用。
- 在主持浮条拖动速度滑杆，并使用 `←`、`→`、`⌥⌘←`、`⌥⌘→`，确认滚动实时变速且不会暂停或复位。
- 分别开启“减少透明度”和 VoiceOver 检查可读性。
- 完成一次 60–120 分钟真实会议耐久测试。

# 主持浮窗滚动速度控制设计

## 目标

在主持浮窗的控制条中直接提供连续可拖拽的自动滚动速度调节，同时增加在鼠标穿透状态下仍可使用的全局快捷键。不得用“减速/加速”点按按钮代替连续调节。完成后交付经过测试和签名校验的 Apple Silicon macOS App。

## 现状

Connection Prompter 1.1 已有平滑自动滚动，速度范围为 0.1–3.0 行/秒，默认值为 0.5 行/秒，并会随会话保存。当前速度滑杆只在主窗口的“主持显示”设置弹窗中；截图所示主持浮窗控制条仅提供开始/暂停和回到开头，因此主持过程中不能直接调整速度。

本次升级以 `feature/v1-1` 分支为基线，保留多文稿、真透明背景、连续滚动、People View、鼠标穿透和现有快捷键等 1.1 功能。

## 方案选择

采用“浮条拖拽滑杆 + 全局快捷键”的组合方案：它既提供直观、连续的指针调节，也覆盖鼠标穿透或不便操作浮条的场景。

未采用的方案：

- 仅使用拖拽滑杆：界面最简单，但鼠标穿透开启后无法操作。
- 仅使用快捷键：占用空间最少，但缺少当前速度的可见反馈，发现性较差。
- 使用减速/加速按钮：与用户明确要求的非点按式交互冲突。

## 主持浮条交互

速度控件放在“回到开头”和 People View 之间，与自动滚动操作归为同一组。控件由速度图标、横向系统滑杆和一位小数的实时数值组成；滑杆范围继续使用 0.1–3.0 行/秒、步进 0.1。它在拖动时立即改变正在运行的滚动速度，不暂停、不复位，也不改变当前位置。

控制条在 500 pt 最小面板宽度和 520 pt People View 宽度下必须完整容纳，不裁切现有按钮。滑杆提供“自动滚动速度”辅助功能名称、以“行/秒”为单位的辅助功能值，以及包含快捷键提示的悬停说明。主窗口设置中的原速度滑杆继续保留，并与浮条显示同一个持久化值。

## 快捷键

新增两项全局快捷键：

- `⌥⌘←`：速度降低 0.1 行/秒。
- `⌥⌘→`：速度提高 0.1 行/秒。

速度始终限制在 0.1–3.0 行/秒，并规整到一位小数，避免连续调整产生浮点显示误差。快捷键只改变速度，不会自动开始、暂停或复位滚动。它们同时出现在“主持”菜单和 README 快捷键说明中。若系统快捷键注册冲突，沿用现有逐项失败提示，不影响其他快捷键。

## 状态与代码边界

`AppState` 增加专用的速度设置与增减方法，负责步进规整、范围限制和自动保存；速度变化不触发无关的分页重建，以保证拖拽顺滑。`AppCoordinator` 只转发浮条、菜单和全局快捷键的意图。`GlobalHotkeyManager` 增加两个独立动作和描述符。`PresenterView` 增加紧凑的速度控件并绑定同一状态，不创建第二份速度状态。

现有存档格式无需迁移：`autoScrollSpeed` 字段、默认值和范围均保持不变。

## 测试与验收

按测试优先方式覆盖以下行为：

- 速度设置会规整到 0.1 步进并限制在 0.1–3.0。
- 快捷键增减速度且在上下限停止；所有全局快捷键动作和标识保持唯一。
- 主持浮窗可找到“自动滚动速度”滑杆，拖到不同位置后数值随之改变。
- 速度改变后自动滚动继续运行，不复位当前位置。
- 现有单元测试和界面测试全部通过。

视觉验收包含正常 640 pt 面板、500 pt 最小宽度和 520 pt People View，确认滑杆、数值与现有按钮无重叠或裁切。Release 产物更新为 1.2（build 3），仅包含 arm64，保留 App Sandbox，以本机临时签名打包；交付 `.app` 和便于传输的 `.zip`，并用系统签名工具、架构工具和启动冒烟测试验证。
